# EnglishEasy 🚀

Личное веб-приложение для изучения английского до уровня B2: игра с серией дней, XP и уровнями, карточки с интервальным повторением, сериалы, ежедневные разговоры и «боссы» (ролевые диалоги) с Claude, строгий ежедневный отчёт.

Работает без сервера (чистые HTML/CSS/JS), офлайн, устанавливается на iPhone и Mac как приложение. Прогресс хранится локально на устройстве (перенос — через «Резервную копию» во вкладке «Прогресс»).

Локальный запуск: `python3 -m http.server 5173` и открыть http://localhost:5173
