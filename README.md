# EnglishEasy

Личная программа изучения английского от A2 до B2 примерно за 6 месяцев: 1,5–2 часа в день — слова, грамматика, слух, чтение, сериалы и разговоры с Claude.

## Что внутри
- **Сегодня** — 7 заданий в день (карточки, грамматика, диктант, чтение, серия, разговор с Claude, отчёт). Галочек нет: каждое задание засчитывается результатом. День засчитан при 5 из 7; серия дней, XP, уровни, заморозки.
- **Слова** — ~1480 слов и фраз A2 → B1 → B2 с эмодзи-подсказками; интервальное повторение; знакомые слова нужно напечатать по-английски (с прощением опечаток); проверка произношения микрофоном; умная нагрузка (меньше новых слов, когда много повторений); колода «Ошибки» из итогов Claude; свои слова.
- **Уроки** — 32 урока грамматики по порядку (правило → 12 заданий → письменное ДЗ) + 576 доп. заданий для повторения; 72 текста для чтения A2–B2 с переводом слов по нажатию, озвучкой и вопросами на понимание; шпаргалки.
- **Слух** — диктант (1000+ фраз под уровень, подсветка услышанных слов), shadowing-студия с записью голоса, 24 мультфильма и сериала с записью фраз и пересказа после серии.
- **Боссы** — 14 ролевых разговоров с Claude; победу засчитывает вердикт Claude.
- **Итог от Claude (#EE)** — в конце разговора, боя, ДЗ или теста Claude пишет блок #EE; приложение засчитывает задание, добавляет новые слова в карточки, ошибки — в колоду «Ошибки», оценку — в график речи.
- **Прогресс** — прогноз до B2, оценки речи, план на 24 недели, календарь, тест уровня, напоминание в Календаре (.ics), резервная копия в файл.

## Технически
Чистые HTML/CSS/JS без сборки и сервера, работает офлайн (service worker), устанавливается на iPhone и Mac как приложение. Прогресс хранится локально на устройстве; перенос между устройствами — «Резервная копия» во вкладке «Прогресс».

| Файл | Что в нём |
|---|---|
| `data.js` | базовые слова, сериалы, боссы, темы разговоров, шпаргалки |
| `words.js` | большой словарь A2–B2 |
| `grammar.js` | курс грамматики: уроки и задания |
| `grammar-extra.js` | доп. задания для повторения |
| `reading.js` | библиотека текстов для чтения |
| `plan.js` | план на 24 недели |
| `app.js` | логика приложения |

Локальный запуск:

```bash
python3 -m http.server 5173
```

и открыть http://localhost:5173
