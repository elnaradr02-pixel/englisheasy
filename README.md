# EnglishEasy — «Paper & Tea on Kettle Island»

Уютная рисованная история + личный английский для методиста в EdTech, которая делает продукты с ИИ, хочет путешествовать и работать в международной компании.

## Один день (~35 минут)
1. **Разминка** — вспоминаешь слова прошлых дней без блокнота (интервалы 1 → 3 → 7 → 14 → 30 дней).
2. **Сцена** — 5–7 минут истории: акварельная картина сверху, реплики с субтитрами и озвучкой, выбор, вопрос на понимание, ответ героине.
3. **Блокнот** — переписываешь от руки 8 слов (эмодзи, пример из истории и личный пример), 3 фразы для жизни и правило-схему.
4. **Задачи** — 8 задач решаешь на бумаге, потом проверяешь себя.
5. **Скажи о себе** — 3 фразы вслух про свою работу, жизнь и планы (можно записать себя).

После дня — по желанию 10 минут голосового разговора с Claude на сегодняшних словах.

## Сезон 1 (10 дней)
to be → Present Simple → вопросы → there is/are → can → Present Continuous → was/were → Past Simple → going to → сравнения. Темы фраз: знакомство, рассказ о работе, small talk и сериалы, отель и перелёт, навыки и ИИ, видеозвонки, соцсети, рассказ о проекте на собеседовании, планы работать за границей, своё мнение.

Иллюстрации — оригинальные SVG-картины в уютной акварельной манере (`art/`).
